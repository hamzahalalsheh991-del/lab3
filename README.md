# Лабораторная работа №3 — метеоданные шести городов России

Notebook реализует EDA, приведение исходных файлов к дневной частоте, инженеринг признаков, классификацию климатического режима с MiniRocket, отдельный прогноз температуры на 1–30 суток для каждого города и диагностические графики/метрики.

## Структура

```text
weather_lab/
├── data/raw/                 # исходные parquet-файлы, 2019–2025
├── notebooks/
│   └── Лабораторная_3_Метеоданные.ipynb
├── reports/                  # таблицы прогнозов и метрик после запуска
└── requirements.txt
```

## Запуск

Требуется Python 3.10 или новее.

```bash
python -m venv .venv
# Windows:
.venv\Scripts\activate
# Linux/macOS:
source .venv/bin/activate
pip install -r requirements.txt
jupyter notebook notebooks/Лабораторная_3_Метеоданные.ipynb
```

Распакуйте все исходные Parquet-файлы в `data/raw/`. Notebook запускайте из корневой папки проекта, последовательно сверху вниз. На первом запуске могут потребоваться несколько минут на MiniRocket и формирование прогнозных обучающих примеров.

## Карта климатических классов

- Умеренно-континентальный: Москва, Санкт-Петербург
- Черноморский субтропический: Сочи, Геленджик
- Дальневосточный муссонный: Благовещенск, Находка

Это укрупнённая учебная группировка. Она обеспечивает не менее двух городов на класс. Для выбора отдельной модели города при прогнозировании дополнительно используется известный идентификатор метеостанции.

## Данные и преобразования

Данные ресемплируются на дни. Для температуры, влажности, кода погоды, ветра и давления вычисляется дневное среднее; осадки, дождь и снег суммируются. Пропуски визуализируются и анализируются; короткие пропуски интерполируются по времени, более длинные заполняются медианой соответствующего месяца. Экстремальные погодные значения автоматически не удаляются.

## Результаты

Notebook выводит:

- графики временных рядов, распределений, Q-Q, сезонности и корреляций;
- климатические профили городов, PCA и результаты ADF;
- accuracy, macro/weighted precision, recall и F1, confusion matrix и OVR ROC-AUC (если классификатор поддерживает вероятности);
- MAE, RMSE, MAPE с защитой знаменателя 1°C, WAPE и точность направления по городам/горизонтам;
- графики прогнозов и анализ остатков тестами Shapiro–Wilk, Ljung–Box и White;
- `reports/forecast_metrics.csv`, `reports/residual_tests.csv`, `reports/test_forecasts_2025.csv`.

## Интерпретация и ограничения

Деление по времени: обучение до 2023, валидация 2024, тест 2025. Для классификатора используются 30-дневные многомерные окна с шагом 7 дней, разделённые по году окончания окна. Для прогнозирования формируются дневные целевые примеры с контекстом 60 дней и горизонтом 1–30 суток; тестовые выпуски формируются ежемесячно в 2025 году.

Температура в °C бывает близка к нулю и отрицательной, поэтому обычный MAPE здесь плохо интерпретируется; основными метриками являются MAE и RMSE. Данные охватывают лишь семь годовых циклов, поэтому качество не следует трактовать как подтверждение пригодности для оперативных предупреждений. Классы климата заданы как укрупнённая экспертная группировка для учебного эксперимента.
